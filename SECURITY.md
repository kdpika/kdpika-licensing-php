# Security policy

Send vulnerability reports privately to hi@kdpika.com. Use synthetic data in
reproductions; never post customer license keys, activation tokens, management
API keys, private signing keys or state files in public issues.

Include the PHP version, SDK version/commit, reproduction and safe request ID.
Never disable signature/TLS checks to work around a licensing failure.
No fixed response-time SLA or historical support window is promised.
This repository contains only the PHP SDK, not KDPika's backend. Its existing
proprietary license is unchanged by public source availability.
